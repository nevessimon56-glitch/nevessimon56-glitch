## 🚀 Projetos

**[J.A.R.V.I.S.](https://github.com/nevessimon56-glitch/jarvis-assistant)**
Assistente de voz para Windows em Python: ML/NLP local, IA opcional (Gemini/Ollama), automação de PC, visão de tela, plugins, camada de privacidade e ~50 módulos de teste.

**Plataforma de Licitações com IA** *(privado)*
Next.js 15 + Supabase + Gemini: análise de editais, propostas, fiscal/controle e recurso administrativo (Lei 14.133). ~165 APIs, 798 testes e RLS.

**AC Manager** *(privado)*
Gestão de ordens de serviço para empresas de ar-condicionado: técnicos em campo com modo offline e GPS, estoque, financeiro, chat e links para terceiros. React, Node, Prisma e PostgreSQL.

**[Psicologia-](https://github.com/nevessimon56-glitch/Psicologia-)**
SaaS para consultório psicológico: agenda, agendamento online, financeiro, prontuário e site público. Next.js + Supabase + Tailwind.

**[Site do Ar](https://github.com/nevessimon56-glitch/Site-do-Ar)**
Tema Liquid (WDNA) do e-commerce [sitedoar.com.br](https://www.sitedoar.com.br/): página de produto, mega menu, quiz Diagnóstico 360 e checkout.

**[miniguia-prompt](https://github.com/nevessimon56-glitch/miniguia-prompt)**
Apostila de engenharia de prompts em Markdown.
