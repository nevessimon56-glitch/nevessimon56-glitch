`Python` `scikit-learn` `spaCy` `Flask` `Gemini`

Análise de editais com IA, propostas, controle fiscal e recurso administrativo (Lei 14.133). ~165 APIs, ~800 testes, Row Level Security e integrações com APIs públicas.
`Next.js` `TypeScript` `Supabase` `Gemini`

`React` `Node.js` `Prisma` `PostgreSQL` `Capacitor`

### 🎓 Plataforma EdTech para a OAB · *privado*
Mentora de IA, modelo adaptativo do aluno, banco de questões e painel admin com validação de conteúdo jurídico.
`React` `Supabase` `Edge Functions` `OpenAI`

`Next.js` `Supabase` `Tailwind`
